# 第3章 栈和队列

## 3.1 栈

**铁路调度站**

火车站里有一种调度站，用来给车厢重新排顺序。它是一段尽头线：一头接着主线，另一头是死的。

<RailYard />

车厢从右边的主线开进尽头线。要出来，只能倒回同一个口，开到左边的主线上去。

学完这一节，你能一眼看出一个出站顺序调不调得出来。

现在右边开来三节车厢，按1号、2号、3号的顺序进站。进出可以交替：开进几节之后，可以先开出几节，再接着开进。

调度员要把它们排成新的顺序开出去。他得先知道：按2、1、3开出去，能做到吗？按3、1、2呢？

> **本节问题**：哪些出站顺序做得到，哪些永远做不到？

<!-- 分页 -->

**调一调**

先试2、1、3。

第一个要开出的是2号。2号还没进站，先让1号、2号开进去。这时2号在最外面，开出去。接着1号在最外面，开出去。最后3号开进来，再开出去。

<RailYard ops="1进 2进 2出 1出 3进 3出" />

2、1、3做得到。

再试3、1、2。

第一个要开出的是3号。先让1号、2号、3号都开进去，3号在最外面，开出去。下一个要开出1号，可是1号在最里面，2号挡在它外面。

<RailYard ops="1进 2进 3进 3出 1卡" />

尽头线只有一个口。1号要出去，得先让2号出去，那样开出的顺序就成了3、2、1。所以3、1、2做不到。

两次试下来，规律是：**每次只能开出最外面那一节**。

回到本节问题。按要开出的顺序，一节一节看。轮到的车厢还没进站，就让它和排在它前面的车厢依次开进来；它已经在站里，就必须在最外面。每一节都做得到，这个顺序就调得出来。只要有一节轮到时被挡在里面，这个顺序就永远做不到。

<!-- 分页 -->

**什么是栈**

这样的调度站可以看成一个**栈**。

栈是只能在一端插入和删除的线性表。把调度站和栈的示意图放在一起，对照着看：

<div class="figure-pair">
<RailYard ops="1进 2进 3进" last terms />
<StackFigure items="1 2 3" />
</div>

**线性表**。站里的车厢一节挨一节，排成一列：(1, 2, 3)。除了最里面和最外面的两节，每节车厢里面恰好挨着一节，外面恰好挨着一节，一个接一个。所以站里的车厢可以看成一个线性表。

线性表在2.1节讲过。

**只能在一端插入和删除**。能进出的那一端叫**栈顶**，另一端叫**栈底**。尽头线的开口是栈顶，尽头是栈底。现在3号在栈顶，1号在栈底。

插入叫**入栈**，删除叫**出栈**。车厢开进来是入栈，开出去是出栈。一节车厢都没有的时候，叫**空栈**。

普通的线性表可以在任意位置插入和删除。比如编辑器可以在一行字的中间插入一个字符。栈不行，只能动栈顶。所以栈是操作受限的线性表。

**后进先出**。上一页的规律是：每次只能开出最外面那一节。换成栈的说法，就是每次只能出栈栈顶。栈顶总是最后入栈的那一个，所以最后入栈的，最先出栈。这叫**后进先出**，也说成先进后出。

3号最后开进来，停在最外面，最先开出去。1号最先开进来，被2号、3号挡着，要等它们都出去。

**练习3：哪些可以看成栈？**

## 3.2 栈的操作与抽象数据类型

**调度员要对调度站做什么**

3.1节把1、2、3调成了2、1、3开出。看其中一个时刻：1号、2号已经开进站，3号还在右边等着，现在轮到开出2号。

<RailYard ops="1进 2进" waiting="3" asks last />

开出之前，调度员要先看一眼：站里还有没有车？最外面是几号？确认最外面就是2号，才让它开出去。开出之后，他要记下开出的是几号，才知道开出的顺序对不对。接下来，3号还要开进来。

这些事都从一个空的调度站开始。

> **本节问题**：把调度站看成栈，调度员的这些动作，栈要提供哪些操作？

<!-- 分页 -->

**栈的五个操作**

2.2节给线性表定了五个操作。栈是线性表，只是只能动栈顶。把这五个操作逐个改成栈的，就得到栈的五个操作。下面把栈记作S。

**InitStack(S)：建立一个空栈**。对应线性表的Init，没有变。调度站开始时空着，一节车厢都没有。

**StackEmpty(S)：栈空返回1，不空返回0**。对应线性表的Length。栈用不着说第几个，也就用不着数一共有几个，只要知道空不空。调度员问"站里还有没有车"，问的就是这个。

**GetTop(S, &x)：取栈顶元素，用x带回**。对应线性表的Get。线性表可以取第几个，栈只能取栈顶，所以不用说第几个。取完之后栈不变，就像调度员只是看一眼最外面是几号，车不开走：

<StackFigure items="1 2 3" ops="gettop" />

**Push(S, x)：把x放到栈顶**。对应线性表的Insert。线性表要说插在第几个，栈不用说，位置只能是栈顶。x放进来之后，就是新的栈顶。3号开进，就是Push(S, 3)：

<StackFigure items="1 2" ops="push:3" />

**Pop(S, &x)：删除栈顶元素，用x带回**。对应线性表的Delete。同样不用说删第几个，只能删栈顶。和Delete不同的是，Pop还要告诉调用者删掉的是谁，因为调度员得知道开出去的是几号。3号开出，就是Pop(S, &x)，x是3：

<StackFigure items="1 2 3" ops="pop" />

GetTop和Pop为什么用x带回，不像线性表的Get那样直接返回？因为空栈时，它们做不成。线性表的Get做不成时返回'\0'，可栈里放的是车厢编号，任何一个整数都可能是编号，挑不出一个数专门表示"做不成"。所以返回值留着报告做成没做成，栈顶元素用x带回。x前面的&，就是2.5节讲的传地址。

五个操作和线性表的对应如下：

| 线性表 | 栈 | 含义 |
|---|---|---|
| Init(L) | InitStack(S) | 建立一个空栈 |
| Length(L) | StackEmpty(S) | 栈空返回1，不空返回0 |
| Get(L, i) | GetTop(S, &x) | 取栈顶元素，用x带回，栈不变 |
| Insert(L, i, x) | Push(S, x) | 把x放到栈顶 |
| Delete(L, i) | Pop(S, &x) | 删除栈顶元素，用x带回 |

栈的操作都没有i，因为位置总是栈顶。空栈没有栈顶，所以不能GetTop，也不能Pop。栈满了怎么办，是实现时的事。

3.1节说的是栈"是什么"：只能在一端插入和删除的线性表。这五个操作说的是栈"能做什么"。两样合起来，就是栈的**抽象数据类型**。和2.2节线性表的抽象数据类型一样，它只说是什么、能做什么，不说元素怎么存、操作怎么做。

**例题：用五个操作调出2、1、3**

> **题目**：1号、2号、3号车厢按这个顺序开到调度站。把调度站看成栈S，要按2、1、3的顺序开出，依次调用哪些操作？每次开出时，x是几？

**分析**。按要开出的车厢，一节一节写。

1. 开始：调用InitStack(S)，S是空栈。
2. 开出2号：2号还没进站，先让1号、2号入栈，调用Push(S, 1)、Push(S, 2)。这时栈顶是2，调用Pop(S, &x)，x是2。
3. 开出1号：1号现在是栈顶，调用Pop(S, &x)，x是1。
4. 开出3号：3号还没进站，调用Push(S, 3)。它就是栈顶，再调用Pop(S, &x)，x是3。

<StackFigure ops="init push:1 push:2 pop pop push:3 pop" />

> **答案**：依次调用InitStack(S)、Push(S, 1)、Push(S, 2)、Pop(S, &x)、Pop(S, &x)、Push(S, 3)、Pop(S, &x)。三次Pop带回的x依次是2、1、3。

调度员的每一个动作都是五个操作之一，没有一步需要知道车厢存在哪里。下一节给栈选一种存法，这串调用不用改。

## 3.3 顺序栈

**栈顶放在哪一头**

3.2节只说了栈能做什么，没说怎么存。现在把栈放进内存。

栈是线性表，2.3节的顺序表可以直接拿来用：一段连续的格子，元素从第0格开始一个挨一个放。只剩一个问题：栈只在一端进出，这一端放在数组的哪一头？

两种放法都试一下。站里已经有1号、2号、3号，3号是栈顶，现在Push(S, 4)。

放法一：栈底在第0格，栈顶在末尾。

```
         0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
Push前 │ 1 │ 2 │ 3 │   │   │
       ├───┼───┼───┼───┼───┤
Push后 │ 1 │ 2 │ 3 │ 4 │   │
       └───┴───┴───┴───┴───┘
```

4直接放进第3格，谁都不用挪。

放法二：栈顶在第0格。

```
         0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
Push前 │ 3 │ 2 │ 1 │   │   │
       ├───┼───┼───┼───┼───┤
Push后 │ 4 │ 3 │ 2 │ 1 │   │
       └───┴───┴───┴───┴───┘
```

要先把1、2、3各往后挪一格，才能空出第0格放4。Pop也一样，删掉第0格之后，后面的都要往前挪一格。

这和2.7节的结论一样：顺序表在末尾插入、删除，一个都不用挪；在开头插入、删除，要挪n个。栈的进出全在栈顶，所以栈顶放在末尾，栈底放在第0格。

> **本节问题**：栈底在第0格、栈顶在末尾，栈的五个操作怎么用C语言写出来？

<!-- 分页 -->

**顺序栈**

用顺序存储的栈叫**顺序栈**。它和顺序表一样，是一段连续的格子，再加一个数记着栈里有几个元素：

```c
#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];   /* 存放元素的连续空间，栈底在第0格 */
    int top;             /* 栈里元素的个数 */
} SeqStack;
```

元素是整数，因为要放的是车厢编号。

top就是顺序表的length，换个名字，是因为它正好指着栈顶：元素放在第0格到第top−1格，栈顶元素在第top−1格，第top格是下一个空格。下面的图只画5格，右边的箭头指着第top格：

<div class="figure-pair">
<StackFigure capacity="5" top bare />
<StackFigure items="1 2 3" capacity="5" top bare />
</div>

左边是空栈，top是0。右边放了1、2、3，top是3，栈顶3在第2格，箭头指着空着的第3格。

由此马上得到两个操作。初始化就是让top为0；判空就是看top是不是0：

```c
void InitStack(SeqStack *S) {
    S->top = 0;
}

int StackEmpty(SeqStack *S) {
    return S->top == 0;
}
```

S传的是地址，和2.5节以后的顺序表一样。

栈满时，top等于MAXSIZE。这一条Push会用到。

::: tip 另一种约定：top指着栈顶元素
有的教材让top等于栈顶元素的下标。这时空栈的top是−1，栈满的top是MAXSIZE−1；Push要先把top加1再放，Pop要先取再把top减1。两种约定都对，本书沿用顺序表的length，让top等于元素的个数。
:::

<!-- 分页 -->

**Push：放到栈顶**

栈里是1、2，top是2。现在Push(S, 3)。

**第一步：判断栈满**。top是2，不等于MAXSIZE，放得下。

**第二步：3放进第top格**。第top格就是下一个空格，也就是第2格：

```c
S->data[S->top] = 3;   /* data[2] = 3 */
```

<StackFigure items="1 2" capacity="5" top ops="set:2=3" />

**第三步：top加1**。现在有3个元素了：

```c
S->top++;              /* top = 3 */
```

<StackFigure items="1 2" capacity="5" top ops="set:2=3 top:3" skip="2" bare />

**先放，再加1，顺序不能反**。top指着的是空格。先加1，top就变成3，3会放进第3格；第2格空着没放东西，却已经算在栈里了。

写成函数。要放的是x，放进第top格，再把top加1。放不下返回0，放好了返回1：

```c
int Push(SeqStack *S, int x) {
    if (S->top == MAXSIZE) return 0;      /* 第一步：栈满，放不下 */
    S->data[S->top] = x;                  /* 第二步：x放进第top格 */
    S->top++;                             /* 第三步：top加1 */
    return 1;
}
```

<!-- 分页 -->

**Pop：删除栈顶，用x带回**

栈里是1、2、3，top是3。现在Pop(S, &x)。

**第一步：判断栈空**。top是3，不是0，有东西可删。

**第二步：top减1**。栈顶元素在第top−1格，也就是第2格。top减成2，第2格就不算在栈里了：

```c
S->top--;              /* top = 2 */
```

<StackFigure items="1 2 3" capacity="5" top ops="top:2" />

格子里的3还在，图里画成灰色。它不用擦掉：top以上的格子都算空，下次Push会直接把它盖掉。

**第三步：用x带回第top格**。top现在是2，第2格里就是刚删掉的3：

```c
*x = S->data[S->top];  /* x = data[2]，也就是3 */
```

<StackFigure items="1 2 3" capacity="5" top ops="top:2 read:2" skip="2" bare />

这里的顺序和Push正好相反：Push先放再加，Pop先减再取。因为top指着的是空格，栈顶在它下面一格。

写成函数。栈空返回0，删好了返回1，删掉的元素用x带回：

```c
int Pop(SeqStack *S, int *x) {
    if (S->top == 0) return 0;            /* 第一步：栈空，没有可删的 */
    S->top--;                             /* 第二步：top减1 */
    *x = S->data[S->top];                 /* 第三步：用x带回第top格 */
    return 1;
}
```

为什么x是`int *`，不是`int`？Pop要把删掉的元素交给调用者，也就是要改调用者自己的变量。如果参数写成`int x`，调用时复制给函数的是调用者那个x的值。函数里给x赋值，改的只是这份复制品，调用者的x不变，和2.5节的Inc1一样。

所以调用时传的是x的地址`&x`，参数用存地址的`int *`。`*x = …`顺着地址改的，就是调用者的x。

<!-- 分页 -->

**GetTop：取栈顶**

GetTop和Pop只差一点：只看，不删，所以top不变。栈顶元素在第top−1格，直接读出来：

```c
int GetTop(SeqStack *S, int *x) {
    if (S->top == 0) return 0;            /* 栈空，没有栈顶 */
    *x = S->data[S->top - 1];             /* 栈顶在第top-1格 */
    return 1;
}
```

**把五个操作合起来**

五个函数都写好了。再写一个main，照着3.2节的例题，用顺序栈把1、2、3调成2、1、3：

```c
int main(void) {
    SeqStack S;
    int x;
    InitStack(&S);
    Push(&S, 1);
    Push(&S, 2);
    Pop(&S, &x);  printf("%d ", x);
    Pop(&S, &x);  printf("%d ", x);
    Push(&S, 3);
    Pop(&S, &x);  printf("%d\n", x);
    printf("栈空吗：%d\n", StackEmpty(&S));
    return 0;
}
```

```

```

main里的调用和3.2节例题一一对应，只是S前面多了&，因为函数要的是地址。存法是这一节才定的，调用的顺序一个都没变。

五个操作都只碰栈顶那一格和top，一个元素都不挪，时间复杂度都是O(1)。

完整的程序放在下面，可以直接复制运行：

```c
#include <stdio.h>

#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];
    int top;
} SeqStack;

void InitStack(SeqStack *S) {
    S->top = 0;
}

int StackEmpty(SeqStack *S) {
    return S->top == 0;
}

int Push(SeqStack *S, int x) {
    if (S->top == MAXSIZE) return 0;      /* 第一步：栈满，放不下 */
    S->data[S->top] = x;                  /* 第二步：x放进第top格 */
    S->top++;                             /* 第三步：top加1 */
    return 1;
}

int Pop(SeqStack *S, int *x) {
    if (S->top == 0) return 0;            /* 第一步：栈空，没有可删的 */
    S->top--;                             /* 第二步：top减1 */
    *x = S->data[S->top];                 /* 第三步：用x带回第top格 */
    return 1;
}

int GetTop(SeqStack *S, int *x) {
    if (S->top == 0) return 0;            /* 栈空，没有栈顶 */
    *x = S->data[S->top - 1];             /* 栈顶在第top-1格 */
    return 1;
}

int main(void) {
    SeqStack S;
    int x;
    InitStack(&S);
    Push(&S, 1);
    Push(&S, 2);
    Pop(&S, &x);  printf("%d ", x);
    Pop(&S, &x);  printf("%d ", x);
    Push(&S, 3);
    Pop(&S, &x);  printf("%d\n", x);
    printf("栈空吗：%d\n", StackEmpty(&S));
    return 0;
}
```

## 3.4 链栈

**栈顶放在哪一头**

3.3节用一段连续的格子存栈。栈也可以用2.9节的链表来存：每个元素一个结点，用地址连起来。

和顺序栈一样，先要定栈顶放在哪一头。还是存1、2、3，3是栈顶，有两种放法。

放法一：第一个结点是栈底，栈顶在表尾。

```
L = 100
  │
  ▼
┌───┬─────┐     ┌───┬─────┐     ┌───┬─────┐
│ 1 │ 109 │────►│ 2 │ 105 │────►│ 3 │  0  │
└───┴─────┘     └───┴─────┘     └───┴─────┘
    100             109             105
```

Pop要删掉3结点，就得把2结点的地址格改成0。可2结点在哪？链表只记着第一个结点的地址，只能从L出发一个一个走过去。栈里有n个元素，就要走n−1步。

放法二：第一个结点是栈顶。

```
S = 105
  │
  ▼
┌───┬─────┐     ┌───┬─────┐     ┌───┬─────┐
│ 3 │ 109 │────►│ 2 │ 100 │────►│ 1 │  0  │
└───┴─────┘     └───┴─────┘     └───┴─────┘
    105             109             100
```

Pop删的是第一个结点：把S改成3结点地址格里的109，一步就到。Push也只是在最前面接一个结点，一步都不用走。

这和2.15节的结论一样：链表在头部插入、删除是O(1)，在尾部是O(n)，正好和顺序表相反。所以链栈的栈顶放在表头，也和顺序栈正好相反。两种存法，都把栈顶放在自己最省事的那一头。

**链栈**

用链式存储的栈叫**链栈**。栈顶就是第一个结点，所以头指针就是栈顶指针，记作S。

结点和2.9节的一样，只是数据格放整数：

```c
typedef struct StackNode {
    int data;                  /* 数据格 */
    struct StackNode *next;    /* 地址格：下面一个结点的地址 */
} StackNode, *LinkStack;
```

StackNode是结点类型，LinkStack是指向结点的指针类型，和2.9节的Node、LinkList是一个意思。

链栈也竖着画，栈顶在上。左边是空栈，右边放了1、2、3：

<div class="figure-pair">
<LinkStackFigure />
<LinkStackFigure items="1 2 3" />
</div>

空栈的S是NULL。放了1、2、3之后，S是105，指着栈顶3结点；3结点的地址格指着2结点，2结点指着1结点；栈底1结点的地址格是0，表示下面没有了。

**不要头结点**。2.13节给链表加了头结点，是为了让第0个结点也有前一个结点，插入、删除不用分情形。链栈只在第0个结点进出：Push是插在第0个，Pop是删第0个，从来不用找前一个结点。头结点在这里没有用处，所以链栈不加。

由此马上得到两个操作。初始化就是让S为NULL；判空就是看S是不是NULL：

```c
void InitStack(LinkStack *S) {
    *S = NULL;
}

int StackEmpty(LinkStack *S) {
    return *S == NULL;
}
```

::: tip 为什么写*S
Push、Pop都要改S本身，让它指向另一个结点。所以调用时传的是S的地址，参数是`LinkStack *`，函数里用`*S`取到S。这和2.10节的`*L`一样。
:::

链栈没有"栈满"：只要还申请得到结点，就能Push。

**Push：放到栈顶**

栈里是1、2，S是109。现在Push(S, 3)。这和2.11节"在第0个位置插入结点"是同一件事。

**第一步：申请结点q，放3**。假设申请到的是105号：

```c
StackNode *q = (StackNode *)malloc(sizeof(StackNode));
q->data = 3;
```

<LinkStackFigure items="1 2" ops="new:3" />

q的地址格还没填，画成问号。申请不到时malloc返回NULL，Push就返回0。

**第二步：q指向原来的栈顶**。原栈顶2结点的地址109正记在S里，抄给q的地址格：

```c
q->next = *S;    /* q->next = 109 */
```

<LinkStackFigure items="1 2" ops="new:3 link" skip="2" />

**第三步：S指向q**。3结点成了新的栈顶：

```c
*S = q;          /* S = 105 */
```

<LinkStackFigure items="1 2" ops="new:3 link move" skip="3" />

**先连上，再改S，顺序不能反**。先改S，原栈顶的地址109就从S里丢了，q的地址格再也抄不到它，1、2两个结点就找不回来了。

写成函数。要放的是x；申请不到结点返回0，放好了返回1：

```c
int Push(LinkStack *S, int x) {
    StackNode *q = (StackNode *)malloc(sizeof(StackNode));  /* 第一步：申请结点放x */
    if (q == NULL) return 0;
    q->data = x;
    q->next = *S;                         /* 第二步：新结点指向原栈顶 */
    *S = q;                               /* 第三步：S指向新结点 */
    return 1;
}
```

栈是空的时候，S是NULL，第二步让q的地址格得到NULL，正好表示下面没有了。不用另写代码。

<!-- 分页 -->

**Pop：删除栈顶，用x带回**

栈里是1、2、3，S是105。现在Pop(S, &x)。这和2.12节"删除第0个结点"是同一件事，只多了一步：用x带回删掉的值。

**第一步：判断栈空**。S是105，不是NULL，有东西可删。

**第二步：q记下栈顶结点，用x带回它的值**：

```c
StackNode *q = *S;   /* q = 105 */
*x = q->data;        /* x = 3 */
```

<LinkStackFigure items="1 2 3" ops="take" />

**第三步：S指向下一个结点**。3结点的地址格是109，抄给S，2结点成了栈顶：

```c
*S = q->next;        /* S = 109 */
```

<LinkStackFigure items="1 2 3" ops="take next" skip="2" />

**第四步：释放q**。3结点已经不在栈里了，还给系统：

```c
free(q);
```

<LinkStackFigure items="1 2 3" ops="take next free" skip="3" />

**先改S，再释放，顺序不能反**。先free(q)，3结点就还给了系统，再读q->next，读的是已经不归你的内存，读到什么说不准。这也是第二步要先用q记下栈顶的原因：S改走之后，只有q还找得到3结点。

写成函数。栈空返回0，删好了返回1：

```c
int Pop(LinkStack *S, int *x) {
    if (*S == NULL) return 0;             /* 第一步：栈空，没有可删的 */
    StackNode *q = *S;                    /* 第二步：记下栈顶结点，用x带回它的值 */
    *x = q->data;
    *S = q->next;                         /* 第三步：S指向下一个结点 */
    free(q);                              /* 第四步：还给系统 */
    return 1;
}
```

**GetTop：取栈顶**

栈顶就是S指着的结点。GetTop只读它的数据格，S不动，也不释放：

```c
int GetTop(LinkStack *S, int *x) {
    if (*S == NULL) return 0;             /* 栈空，没有栈顶 */
    *x = (*S)->data;                      /* 栈顶就是S指向的结点 */
    return 1;
}
```

`(*S)->data`的括号不能省：先用`*S`取到S，再用`->`读它指着的结点。

**把五个操作合起来**

五个函数都写好了，还要写main。先别动手，预测一下：3.3节的main要改多少？

3.3节的main只调用了五个操作，没有碰过data和top。链栈的五个操作，名字和用法都和顺序栈一样。所以预测：main只改一处，把`SeqStack`换成`LinkStack`。

```c
int main(void) {
    LinkStack S;            /* 原来是 SeqStack S; */
    int x;
    InitStack(&S);
    Push(&S, 1);
    Push(&S, 2);
    Pop(&S, &x);  printf("%d ", x);
    Pop(&S, &x);  printf("%d ", x);

    Pop(&S, &x);  printf("%d\n", x);

```


和3.3节一模一样，预测成立。这就是3.2节的抽象数据类型带来的好处：main只依赖"能做什么"，"怎么存"可以整个换掉。

两种栈的五个操作都是O(1)。区别在空间上：顺序栈事先定好MAXSIZE，放满就不能再放；链栈要多少申请多少，但每个元素多占一个地址格，每次Push还要申请一次结点。

完整的程序放在下面，可以直接复制运行：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct StackNode {
    int data;
    struct StackNode *next;
} StackNode, *LinkStack;

void InitStack(LinkStack *S) {
    *S = NULL;
}

int StackEmpty(LinkStack *S) {
    return *S == NULL;
}

int Push(LinkStack *S, int x) {
    StackNode *q = (StackNode *)malloc(sizeof(StackNode));  /* 第一步：申请结点放x */
    if (q == NULL) return 0;
    q->data = x;
    q->next = *S;                         /* 第二步：新结点指向原栈顶 */
    *S = q;                               /* 第三步：S指向新结点 */
    return 1;
}

int Pop(LinkStack *S, int *x) {
    if (*S == NULL) return 0;             /* 第一步：栈空，没有可删的 */
    StackNode *q = *S;                    /* 第二步：记下栈顶结点，用x带回它的值 */
    *x = q->data;
    *S = q->next;                         /* 第三步：S指向下一个结点 */
    free(q);                              /* 第四步：还给系统 */
    return 1;
}

int GetTop(LinkStack *S, int *x) {
    if (*S == NULL) return 0;             /* 栈空，没有栈顶 */
    *x = (*S)->data;                      /* 栈顶就是S指向的结点 */
    return 1;
}

int main(void) {
    LinkStack S;
    int x;
    InitStack(&S);
    Push(&S, 1);
    Push(&S, 2);
    Pop(&S, &x);  printf("%d ", x);
    Pop(&S, &x);  printf("%d ", x);
    Push(&S, 3);
    Pop(&S, &x);  printf("%d\n", x);
    printf("栈空吗：%d\n", StackEmpty(&S));
    return 0;
}
```

## 3.5 栈的应用：括号匹配

**括号配对吗**

写程序时，括号总是成对出现：圆括号`()`、方括号`[]`、花括号`{}`。编辑器会把配成一对的括号标出来；少了一个、多了一个，编译器就报错。

比如这一行：

```
a [ ( b + c ) * d ]
  │ └───────┘     │
  └───────────────┘
```

圆括号配圆括号，方括号配方括号，里面的一对整个套在外面那一对里。这一行是配对的。

下面三行都不配对，错法各不相同：

- `(]`：类型对不上，圆括号碰上了方括号。
- `())`：右括号多了一个，最后那个`)`找不到左括号。
- `(()`：左括号多了一个，第一个`(`一直没等到右括号。

学完这一节，你能写出一个函数，读进一行字，判断里面的括号配不配对。

> **本节问题**：程序从左往右读一行字，怎么判断括号配不配对？

<!-- 分页 -->

**方法一：数个数**

先只看圆括号。读`(()())`，它配对吗？

一个直接的想法：数一数还有几个左括号没配上。读到左括号，个数加1；读到右括号，配掉一个，个数减1。把读完每个字符之后的个数，写在这个字符下面：

```
字符   (  (  )  (  )  )
个数   1  2  1  2  1  0
```

读完时个数是0，所有左括号都配上了，配对。

再看两个错例。先看`())`：

```
字符   (  )  )
个数   1  0  ?
```

读到第二个`)`时，个数已经是0，前面没有还没配上的左括号，这个`)`配不上。右括号多了，表现为**减之前个数已经是0**。

再看`(()`：

```
字符   (  (  )
个数   1  2  1
```

读完时个数是1，还有一个左括号没配上。左括号多了，表现为**读完时个数不是0**。

于是得到方法一：用一个数count，记还没配上的左括号有几个。

```text
count = 0
for s 里的每个字符 c:
    if c 是 '(':
        count = count + 1
    else if c 是 ')':
        if count == 0: return 不配对     // 右括号多了
        count = count - 1
return count == 0                       // 不是0，就是左括号多了
```

这是**伪代码**：有循环、if和return，结构和C一样，但条件用中文说，先不管C怎么写。

只有圆括号时，这个办法完全够用。

<!-- 分页 -->

**方法二：配给最近的那一个**

现在加上方括号。读`([)]`，照方法一，圆括号、方括号各数各的：

```
字符       (  [  )  ]
圆括号个数 1  1  0  0
方括号个数 0  1  1  0
```

两个数都没有在0的时候再减，读完也都是0。照方法一，这一行配对。可它不配对：`)`来的时候，`(`和它之间还夹着一个没配上的`[`。

问题出在哪？个数只说了"还有几个没配上"，没说"最近一个没配上的是哪种括号"。而`)`该配谁，恰恰要看这个。

那就看看，读到右括号时，它到底该配谁。读`a[(b+c)*d]`，把还没配上的左括号按读到的先后摞起来，后读到的放上面：

<StackFigure ops="push:[ push:( pop pop empty" labels="开始|读到 [~摞上去|读到 (~摞上去|读到 )~拿走 (，是一对|读到 ]~拿走 [，是一对|读完~什么都不剩，配对" />

读到`)`时，摞着的是`[`和`(`。`)`配的是`(`，也就是上面那个、最近读到的那个。配上就拿走。再读到`]`，最上面剩下`[`，正好配上。

括号一层套一层，里面的一对必须先合上，外面的才能合上。所以：

**右括号总是和最近一个还没配上的左括号配。**

最近的先配，就是后进先出。刚才那一摞，就是一个栈：还没配上的左括号入栈；读到右括号，出栈一个，看是不是一对。

写成伪代码：

```text
InitStack(S)
for s 里的每个字符 c:
    if c 是左括号:
        Push(S, c)                         // 等着配
    else if c 是右括号:
        if StackEmpty(S): return 不配对    // 右括号多了
        Pop(S, &left)                      // 最近一个没配上的左括号
        if left 和 c 不是一对: return 不配对   // 类型对不上
return StackEmpty(S)                       // 栈不空，就是左括号多了
```

和方法一对照着看：count加1换成了Push，count减1换成了Pop，`count == 0`换成了StackEmpty。方法一的count，其实就是栈的高度。只有一种括号时，栈里放的都一样，记住高度就够了；括号一多，就得记住每一层放的是什么。

**三种错，在哪一步发现**

再看开头的三行错例。每一种错，都对应伪代码里的一个return：

<StackFigure ops="push:( pop empty" skip="3" bare labels="()) 读到第二个 )~栈空，没有左括号可配" />
<StackFigure ops="push:( push:( pop empty" skip="4" bare labels="(() 读完~栈里还剩 (，不配对" />
</div>

**类型对不上**，在读到右括号、出栈之后发现：`(]`里，`]`让`(`出栈，两个不是一对。对应`if left 和 c 不是一对`那一行。

**右括号多了**，在读到右括号、栈却是空的时候发现：`())`里，第一个`)`已经把`(`配掉了，第二个`)`来时栈里什么都没有。对应`if StackEmpty(S)`那一行。

**左括号多了**，要读完才发现：`(()`里，读到最后，栈里还剩一个`(`。读的过程中看不出来，因为后面也许还会有右括号。对应最后一行`return StackEmpty(S)`。

三种错各有一个return把守，一种都不会漏。

**写成函数**

照方法二的伪代码，一行一行写成C。

栈要放的是括号，也就是字符。3.3节的顺序栈放的是int，要把元素换成char：结构体里的`data`，Push、Pop、GetTop的参数`x`，一共四处，把int改成char。五个函数的写法一个字都不用动。

::: tip 只改一处：typedef
如果当初写`typedef int ElemType;`，所有放元素的地方都写`ElemType`，换类型时只要把这一行改成`typedef char ElemType;`。很多教材就这样写。
:::

先写一个小函数，判断两个括号是不是一对：

```c
int Pair(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}
```

再照伪代码写Match，每一行都对得上。"c 是左括号"写成三个比较，"left 和 c 不是一对"交给Pair。配对返回1，不配对返回0：

```c
int Match(char *s) {
    SeqStack S;
    char left;
    InitStack(&S);
    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            if (!Push(&S, c)) return 0;           /* 左括号：入栈（栈满就当不配对） */
        } else if (c == ')' || c == ']' || c == '}') {
            if (!Pop(&S, &left)) return 0;        /* 栈空：右括号多了 */
            if (!Pair(left, c)) return 0;         /* 出栈的左括号和它不是一对 */
        }
    }
    return StackEmpty(&S);                        /* 读完栈空，才算配对 */
}
```

Match只调用了InitStack、Push、Pop、StackEmpty，没有碰过`data`和`top`。所以把顺序栈换成3.4节的链栈，Match也一个字都不用改。

用几行字试一试：

```c
int main(void) {
    char *tests[] = {"a[(b+c)*d]", "(]", "())", "(()", "{[()()]}", "([)]", ""};
    for (int i = 0; i < 7; i++)
        printf("\"%s\" %s\n", tests[i], Match(tests[i]) ? "配对" : "不配对");
    return 0;
}
```

运行结果：

```
"a[(b+c)*d]" 配对
"(]" 不配对
"())" 不配对
"(()" 不配对
"{[()()]}" 配对
"([)]" 不配对
"" 配对
```

没有括号的空串也算配对：栈从头到尾都是空的。

::: warning 栈会满
栈只有MAXSIZE个格子。左括号一口气套了100层以上，Push就放不下了，Match会把它当成不配对。真要处理这么深的嵌套，把MAXSIZE改大，或者换成链栈。
:::

完整的程序放在下面，可以直接复制运行：

```c
#include <stdio.h>

#define MAXSIZE 100

typedef struct {
    char data[MAXSIZE];
    int top;
} SeqStack;

void InitStack(SeqStack *S) {
    S->top = 0;
}

int StackEmpty(SeqStack *S) {
    return S->top == 0;
}

int Push(SeqStack *S, char x) {
    if (S->top == MAXSIZE) return 0;
    S->data[S->top] = x;
    S->top++;
    return 1;
}

int Pop(SeqStack *S, char *x) {
    if (S->top == 0) return 0;
    S->top--;
    *x = S->data[S->top];
    return 1;
}

int GetTop(SeqStack *S, char *x) {
    if (S->top == 0) return 0;
    *x = S->data[S->top - 1];
    return 1;
}

int Pair(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}

int Match(char *s) {
    SeqStack S;
    char left;
    InitStack(&S);
    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            if (!Push(&S, c)) return 0;           /* 左括号：入栈（栈满就当不配对） */
        } else if (c == ')' || c == ']' || c == '}') {
            if (!Pop(&S, &left)) return 0;        /* 栈空：右括号多了 */
            if (!Pair(left, c)) return 0;         /* 出栈的左括号和它不是一对 */
        }
    }
    return StackEmpty(&S);                        /* 读完栈空，才算配对 */
}

int main(void) {
    char *tests[] = {"a[(b+c)*d]", "(]", "())", "(()", "{[()()]}", "([)]", ""};
    for (int i = 0; i < 7; i++)
        printf("\"%s\" %s\n", tests[i], Match(tests[i]) ? "配对" : "不配对");
    return 0;
}
```

**练习1：在哪一步停下？**

::: quiz 填空
用Match判断`{[(])}`，从左往右读。

- 读第4个字符`]`时，出栈的是 [[(]]
- 所以这一行 [[不配对]]
- Match在第 [[4]] 个字符就返回了，后面的`)}`没有再读

**其他选项**：[、配对、6

前三个字符`{[(`都是左括号，依次入栈，栈顶是`(`。第4个字符`]`让`(`出栈，`(`和`]`不是一对，Match马上返回0，后面两个字符不再读。
:::

**练习2：哪些配对？**

::: quiz 多选
下面哪些是配对的？

- [x] `([]{})`
  `(`入栈；`[`入栈又被`]`配掉；`{`入栈又被`}`配掉；最后`)`配掉`(`，栈空。
- [ ] `(()`
  读完栈里还剩一个`(`，左括号多了。
- [ ] `([)]`
  读到`)`时，出栈的是`[`，不是一对。左右括号个数虽然相等，也不配对。
- [x] `{}[]()`
  三对挨着排，每对都是刚入栈就被配掉。
- [ ] `)(`
  第一个字符`)`来时栈是空的，右括号多了。

判断的办法：右括号总是和最近一个还没配上的左括号配，读完栈要空。只数个数不够，`([)]`就是反例。
:::
