# 一元多项式的运算

本题分三问，逐步完成：第一问读入并整理一个多项式，第二问做加法和减法，第三问做乘法。三问的输入和输出用同一种格式，后一问可以直接使用前一问的代码。

**数据范围（三问相同）**

- 每个多项式的项数 n 满足 0 ≤ n ≤ 100。
- 系数 c 满足 |c| ≤ 1000；合并同类项之后，每项系数的绝对值仍不超过 1000。
- 指数 e 满足 0 ≤ e ≤ 10⁸。

在此范围内，所有结果的系数和指数都在 32 位有符号整数的范围内。

---

## 第一问：整理多项式

### 题目描述

给出一个多项式各项的系数和指数，项的顺序是乱的，同一个指数可能出现多次。请合并同类项，按指数从高到低输出这个多项式。

### 输入格式

一行。第一个整数 n 是项数，后面跟 n 对整数 `c e`，表示一项 c·xᵉ。n 为 0 表示零多项式。

例如 `3 4 5 4 1 -1 0` 表示 3 项：4x⁵、4x、−1。

### 输出格式

一行，格式和输入相同：先输出项数 k，再输出 k 对 `c e`。要求：

- 各项按指数从高到低排列；
- 同一个指数只出现一次（同类项已合并）；
- 系数为 0 的项不输出。

零多项式输出 `0`。

### 样例

**样例 1**

```输入
3 4 1 -1 0 4 5
```

```输出
3 4 5 4 1 -1 0
```

即 4x⁵ + 4x − 1。输入的顺序是乱的，按指数从高到低重排。

**样例 2**

```输入
5 2 2 -1 0 3 5 1 2 -3 2
```

```输出
2 3 5 -1 0
```

即 3x⁵ − 1。x² 出现三次，合并后系数为 0，不输出。

**样例 3**

```输入
4 2 3 5 0 -1 3 1 1
```

```输出
3 1 3 1 1 5 0
```

即 x³ + x + 5。x³ 的两项不相邻，合并后系数为 1，保留。

**样例 4**

```输入
2 4 3 -4 3
```

```输出
0
```

合并后什么都不剩，是零多项式。

## 第二问：加法和减法

### 题目描述

输入两个多项式 A 和 B，输出 A + B 和 A − B。

### 输入格式

两行，第一行是 A，第二行是 B，每行的格式同第一问。

### 输出格式

两行，第一行是 A + B，第二行是 A − B，每行的格式同第一问。

### 样例

**样例 1**

```输入
3 3 5 2 2 -1 0
3 1 5 -2 2 4 1
```

```输出
3 4 5 4 1 -1 0
4 2 5 4 2 -4 1 -1 0
```

A = 3x⁵ + 2x² − 1，B = x⁵ − 2x² + 4x。A + B = 4x⁵ + 4x − 1，其中 x² 的系数为 0，不输出；A − B = 2x⁵ + 4x² − 4x − 1。

**样例 2**

```输入
4 1 2 3 0 2 2 -1 1
2 1 0 -1 1
```

```输出
3 3 2 -2 1 4 0
2 3 2 2 0
```

A 合并后为 3x² − x + 3，B = 1 − x。A + B = 3x² − 2x + 4；A − B = 3x² + 2，其中 x 的系数为 0，不输出。

**样例 3**

```输入
2 1 100000000 1 0
2 1 100000000 1 0
```

```输出
2 2 100000000 2 0
0
```

A = B = x¹⁰⁰⁰⁰⁰⁰⁰⁰ + 1。A + B = 2x¹⁰⁰⁰⁰⁰⁰⁰⁰ + 2；A − B 是零多项式。

## 第三问：乘法

### 题目描述

输入两个多项式 A 和 B，输出 A × B。

### 输入格式

两行，第一行是 A，第二行是 B，每行的格式同第一问。

### 输出格式

一行，A × B，格式同第一问。

### 样例

**样例 1**

```输入
3 3 5 2 2 -1 0
3 1 5 -2 2 4 1
```

```输出
8 3 10 -4 7 12 6 -1 5 -4 4 8 3 2 2 -4 1
```

A = 3x⁵ + 2x² − 1，B = x⁵ − 2x² + 4x，A × B = 3x¹⁰ − 4x⁷ + 12x⁶ − x⁵ − 4x⁴ + 8x³ + 2x² − 4x。

**样例 2**

```输入
2 1 100000000 1 0
2 1 100000000 -1 0
```

```输出
2 1 200000000 -1 0
```

(x¹⁰⁰⁰⁰⁰⁰⁰⁰ + 1)(x¹⁰⁰⁰⁰⁰⁰⁰⁰ − 1) = x²⁰⁰⁰⁰⁰⁰⁰⁰ − 1，中间两项 x¹⁰⁰⁰⁰⁰⁰⁰⁰ 和 −x¹⁰⁰⁰⁰⁰⁰⁰⁰ 抵消。

**样例 3**

```输入
0
3 1 2 3 4 5 6
```

```输出
0
```

A 是零多项式，乘积也是零多项式。
