来源列的含义如下。
- **原样**：书稿原句，一字不改，或者只把一个长句从标点处拆成两拍。
- **小改**：删掉指代词，改符号念法，删掉画面已经显示的半句，或者调整语序。

## 课程段落

这一段课程覆盖 2.1–2.6，到做出编辑器1.0为止。开场提出三个小问，分别在 2.1、2.2、2.3–2.6 回答，都在这一段课程内闭合。开场的写法参照 Gauth 集合课，分五步：

| Gauth 集合课 | 本课 |
|---|---|
| 菜单板：每款饮料是一份配料单 | 搜索框、聊天框：你每天都在一行里敲字 |
| 这样的一组东西叫集合 | 这样排成一列的数据叫线性表 |
| 学完能合并、比较、数清集合 | 学完能用C做出编辑器的第一版 |
| 两个问题：共用哪些配料？一共几种？ | 三个问题：记住什么？做哪些事？怎么放进内存？ |
| 先放一放，先学集合的语言 | 先记住，我们从第一个开始 |
