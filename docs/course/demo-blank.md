# 空位演示 · 双栏稿（不是课程）

演示课程播放器的"空位"元件：例题的空位按拍填上，练习是填空题。帧在 `docs/course/storyboard/demo-blank.frames.ts`，练习题取书稿 2.2 节（`book/chapters/ch02.md`）的两道练习。

生成：`npm run storyboard -- demo-blank`（分镜墙），`COURSE_TTS=edge npm run course:player -- demo-blank`（播放器，用云希配音，不花 fish 额度）。

## 第1屏　例题：空位按拍填上

| 拍 | 画面 | 旁白 | 来源 |
|---|---|---|---|
| 1 | 题目卡；下面三行，每行左边写动作，右边两个虚线空位（调用、表） | 编辑器刚启动，依次敲c、a。填出每一步调用的操作，和调用之后的表。 | 原样 |
| 2 | 第1行两个空位填上 Init(L)、() | 启动：调用Init，表是空表。 | 小改 |
| 3 | 第2行两个空位填上 Insert(L, 0, c)、(c) | 敲c：c放在第0个位置。 | 原样 |
| 4 | 第3行两个空位填上 Insert(L, 1, a)、(c, a)；旁边出现徽章"长度 2" | 敲a：a接在c后面，是第1个位置。 | 原样 |
