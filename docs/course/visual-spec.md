# 课程画面规范

**质感版（Gauth 式）是主推版本**（作者 2026-10-14 定）：新的一节课程动画直接用它。下面第一部分讲新一节怎么做；质感层的详细规则（四条原理、中文调整、版面和图、三层画法、分镜检查清单）在本文最后一节"质感层"。

白板、纸面、贴纸、工作台、手绘、原版线框这几种是**备份风格**，代码和帧文件都保留：
- 分镜墙输出到 `docs/course/storyboard/backup/`，播放器页面输出到 `docs/course/player/<id>/backup/`，两处都不进仓库；
- 网站上不显示，以后要用到类似样式时参考。它们的规则在本文中间的"备份风格"各节。

## 质感版：新一节怎么做

### 流程

1. **写双栏稿** `docs/course/<id>.md`：一行一拍，左栏写画面，右栏写旁白，从书稿改写。
2. **写帧文件** `docs/course/storyboard/<id>.clean.frames.ts`，照 `2-1.clean.frames.ts` 的结构：
   - 头部写这一节的固定部分，比如场景 A/B、左右两栏 `cpane`、练习卡；
   - 每屏只用一两个固定版面，每帧只写"这一拍变了什么"。
3. **生成分镜墙**：`npm run storyboard -- <id>`，输出 `<id>.clean.html`。
4. **体检**：`npm run storyboard:audit -- <id> --shots <目录>`。看版面数和稳定率，再人眼看联系表（规则见"分镜检查清单"）。
5. **作者按帧编号审**，比如 1-07、2-14。
6. **生成播放器**：`npm run course:player -- <id>`，输出 `player/<id>/index.html`，配音用 fish 整屏合成后切成每拍；只改画面时加 `--no-tts`。
7. **发布到网站**：`npm run course:publish -- <id>`，把播放器和配音复制到 `site/public/course/<id>/`（进仓库），再 `npm run build`。这一节的页面会默认显示动画，顶部有"看动画 | 读文字"切换；章首目录在这一节后面标出"▶ 时长"。
8. **导出视频**（需要时）：`npm run course:video -- <id>`。

想同时看几种改法时，先挑几帧做三栏对比页：`npx tsx scripts/style-compare.ts <id>`。

### 每步检查清单（2.2 总结，2026-10-19）

每一步开工前对一遍。括号里是这一条防的问题。

**参考分析**
- 截帧拼成联系表，再用 faster-whisper 转写配音，两者按时间对齐。结论用数字写，比如平均几秒一句、一屏几种版面。（只看录屏会漏掉节奏）
- 先看本节在课程里是什么角色，再到参考里找角色相同的那一节，结构跟它走。（只借零碎几招，屏序还按旧稿）
- 借参考的手法之前，先确认它的前提在本学科成立。（照搬"双胞胎钩子""有重复的干扰项"）

**定结构（先改书稿）**
- 讲操作集的节不设问题页：开头用 Aho 式，讲完再回扣章首的问题、打勾。写法见 `docs/teaching-patterns.md` 第 14 条。
- 前面章节已经定义过的概念，只用一两句回扣。（重复讲一遍）
- 定义句不要暗示列举完了，比如写"这里取最基本的五个"。（读者以为只有这几个）
- 写完对一遍章首承诺的词，确认这一节都兑现了。（比如"查找"没出现）
- 动画里不值得念的话，书稿里多半也不需要；动画要改的地方，书稿跟着改；纯呈现的东西不回改书稿。（一稿两用失效）

**练习**
- 先写出本节的"会做"目标，再按目标出题。写法见第 16 条。（练习测不到核心）
- 例题和练习同型：例题由老师逐空填，没有单独的答案卡。写法见第 15 条。

**双栏稿**
- 先切屏再切拍。一屏超过约 90 秒，就在概念的切点上拆开，版面不变。
- 练习做完只留一拍过门（"下一步"），不念小结；文字版保留节尾卡。（重复）

**帧和分镜墙**
- 开场讲抽象概念，用问题屏双栏：左卡放"是什么"，用一般形式的图；右卡放"要做什么"。不用场景例子，左栏不能空着。
- 否定性的概念（"不说怎么存"），不要画被否定的东西，用屏上已有的元素表达。（问号、幕布会让人以为马上要讲）
- 内容在版面里放不下就换版面，但每屏不超过两种。
- 改了拍号，帧文件里所有按拍号写的表（`cblanks` 的 fill 等）都要同步。分镜墙看不出这个错，空位总是画成填好的，只有播放器里才看得到。
- `storyboard:audit` 查出画布和字号；元素重叠要人眼看联系表。

**配音和播放器**
- 合成前先扫一遍旁白，把没收录的多音字补进 `pronounce.json`。
- `--no-tts` 只复用已有的配音，第一次必须真合成。
- 动效细调放在配音之后，等知道每拍实际说多久。

**发布**
- 每发布一节动画，就把 e2e 里拿来当"没有动画的节"的页面往后挪。
- e2e 大面积失败时，先查 4173 端口是不是别处留下的旧预览。
- 提交时只暂存这一节的文件；同一文件里有别人的改动时，只暂存这一节那一段。

| 练习 | 练习题 | 小标签"练习 N · 多选" + 宋体题干 + "字母 \| 内容"选项（填空：空位 + 选项块）+ 解析位 + 按钮条（检查、看答案、继续）。**这张卡就是作答界面**：外层用 `cquiz`，暂停时播放器直接在卡上作答，画面不换；生成播放器时核对卡上的选项和书稿对得上 | 第3、4屏 |
| 节尾 | 小结 + 下一步 | 小结卡片 + 开场那三枚问题胶囊（答完的打勾，下一个高亮） | 第5屏 |

### 念到哪，看到哪（2026-10-28 作者定，3.6 起）

旁白点名画面上的某个东西时，那一刻画面要把眼睛带过去，不能只靠一拍开头的新元素。帧上写 `cues`（类型见 `scripts/lib/course.ts` 的 `Cue`），播放器按配音里每个字的时间（faster-whisper 转写，存在 `audio/bNNN.t.json`）对齐：

- **移动**：过程动作（读头往右走、入栈、出栈、写到输出带）用 `steps` 在念到那个短语时依次换状态。前后状态里 `data-k` 相同的元素滑过去，带 `data-src` 的新元素从那个元素的位置滑过来。`ctape`/`cstack` 用 `k`、`names`、`src` 给元素起名；同一屏相邻两帧都有带名字的元素时，换帧也不再交叉淡化，元素直接滑过去。"弹出""入栈"这类动作，帧里先画动作前的样子，念到动词那一刻再用 `steps` 换成动作后，不要在拍首就动。
- **聚焦（指示框）**：念到"读到`+`""4 和 2"这类点名时，用 `focus` 让一个深蓝细框指过去，像老师的手指，到下一个聚焦或这一帧结束。目标要先起名（`data-k`）。
  - 框在目标之间滑过去，不熄灭；同一屏换帧时也接着滑。一串聚焦只在开头淡入、结尾淡出，到达时从略大收到贴合。
  - 一次点名几个分开的东西各框一个，挨着的格子合成一个框。
  - **不压暗别的东西**：作者 2026-10-28 定，整屏一暗一亮比目标本身更抢眼。引导只用局部的变化。
  - 有静态描边（如栈的 `ring`）的元素，被聚焦时去掉描边，免得两层框叠在一起。
- **批注**：旁白对框住的东西下判断、给理由时，加 `note`（四五个字的"为什么"），框到了以后画一根红色短弯箭头、再写出红字（`--note`），框滑走前淡出，画面上同时最多一条。默认写在右边，`side: 'b' | 'l'` 换到下面、左边。只是点名的地方不写批注；原来拍首就整句出现的小注，改成念到时的批注，不要两处都写。
- **不放大**：`zoom` 不再用，整屏缩放和压暗一样分散注意力。
- **静态小字还是批注**（作者 2026-10-28 定）：看这句话是"图的一部分"还是"老师当下说的一句话"。
  - **留在画面上**：名字和标签（"栈""放着""小式子"）、会更新的记录（推导列表、栈旁"右边：？→ 4*2"）、约定、定义、结论、结果、验算、两列对照表。这些之后还要回头看。
  - **改成批注**：念到这一刻才说的提问、判断、理由（"能先算吗？""读到 - 才知道""先算这里""比 * 低 → 不弹"）。挂在画面上会成噪音，拍首就出现又和声音对不上。
  - 和指示框作用重复的虚线框（"先算这里"框）也去掉。
- **闪回不滑动**：退回前面某个时刻或换一个例子的帧写 `cut: true`，照旧淡入，元素不滑；名字照样能用来聚焦（3.6 第9屏）。

`storyboard:audit` 会核对每个 `focus` 的目标存在、拍内状态不出画布，并列出"静止拍"：念 4 秒以上、画面上既没有新元素也没有 cue 的拍，逐个看要不要补引导。

# 备份风格：白板版

2026-10-13 定稿草案，等作者看完 `2-1.board2.html` 和 `2-1.board2-xiaolai.html` 后定中文字体。
实现在 `scripts/lib/board.ts`（`--board2` / `--board2-xiaolai`）。

## 换算

画布是 640×360，导出 1080p 时放大 3 倍：**画布 1px = 1080p 3px**。下表同时给出两种字号。

## 字体：一共 4 种

| 用途 | 字体 | 说明 |
|---|---|---|
| 板上中文 | **霞鹜漫黑** 或 **小赖**，二选一 | 同一块板上只用一种中文手写体；层级靠字号和颜色区分，不靠换字体 |
| 板上英文、数字、下标 | **Excalifont** | 直立、好认，`7` 和 `1`、`l` 不会混；缺 `→ ↓ ✓ ✗` 等符号，依次回退到中文手写体、Segoe UI Symbol |
| 代码 | **更纱等宽 Sarasa Fixed SC**（和书站一致） | 短代码、长代码同一种字体；手绘感由代码外面的手画框、当前行的手画下划线提供。到 2.12 再用实帧和 Monaspace 对比后定 |
| 字幕 | **思源黑体 Medium** | 底部安全区，半透明深色底条；字幕追求清楚，不要手绘感 |

字体授权都是 SIL OFL 1.1，全文在 `tools/fonts/OFL-*.txt`；页面里嵌的是按用字裁剪的子集。

## 字号

| 画面元素 | 画布 px | 1080p px |
|---|---|---|
| 章节标题卡（开场停留 ≥2 秒，之后缩到左上角） | 24–32 | 72–96 |
| 页标题 | 26 | 78 |
| 节点值、数组元素、编辑器里的字 | ≥15，格子 24 | ≥44 |
| 下标、格子上下的标签 | ≥12 | ≥36 |
| 讲解要点（每屏 ≤3 行，每行 ≤14 字） | 15–17 | 44–52 |
| 字幕 | 16–18 | 48–56 |
| **任何文字的下限** | **12** | **36** |

书稿里的小字说明在视频里删掉，改由配音讲。

## 墨水颜色（语义固定，整门课不换）

| 颜色 | 用途 |
|---|---|
| 黑 `#1f2023` | 正文、内容框 |
| 蓝 `#1d5fb4` | 标注、解释 |
| 红 `#c42b2b` | 错误、✗、光标、关键结论的圈 |
| 绿 `#237a3b` | 正确、✓ |
| 紫 `#7048e8`（`--ptr`，类名 `.ptr`） | **只给指针和变量名**（head、cur、node），学员靠颜色追踪它 |
| 黄色荧光笔底（`.hl`） | 只给最关键的词 |

## 线条（画布 px）

不用 Rough.js，用 board.ts 里自己生成的单笔笔画（两端收尖，种子取自元素的位置和大小，逐帧不抖）。

| 角色 | 线宽 | 画法 |
|---|---|---|
| 内容（格子、编辑器、节点） | 2.3（≈1080p 7px） | 完整四笔框 |
| 容器（卡片、展开行、问题卡） | 1.6（≈5px） | 细框 |
| 列表行（收起的行、检查项、选项） | 1.3（≈4px） | 只画下划线 |
| 按钮 | 1.6 | 手画一个圈 |

## 描边（halo）

只给**压在线条上的标签**加和背景同色的描边（类名 `.halo`，约 5px），比如指针标签压在箭头上。不全局使用，否则字会显胖。

## 文字出现方式（动效阶段再做）

- 标签和讲解：淡入，或沿书写方向擦除显现，进度由时间 t 决定（render(t)）。
- 关键词：同样用擦除显现，字形就是板上的手写体。
- **不用 Hanzi Writer 的自带动画**：它的笔顺数据取自文鼎楷体和宋体（Arphic Public License），写出来是楷书笔形，和漫黑、小赖不一致；它自己计时，也和 render(t) 冲突。

# 备份风格：纸面版（2026-10-13 试做）

参考 prompt-motion 上 @ik_builds 的 Paper-style 短片。生成命令是 `npm run storyboard -- 2-1 --paper`，帧文件是 `docs/course/storyboard/2-1.paper.frames.ts`，主题代码在 `scripts/lib/paper.ts`。风格定稿后，再把纸面帧合并回 `2-1.frames.ts`，并同步改双栏稿的画面列。

## 两层分工

| 层 | 放什么 | 怎么画 |
|---|---|---|
| **纸片层** | 卡片、手风琴、问题卡、练习题、格子、编辑器 | 印刷体：正文用系统黑体，等宽内容用更纱等宽；纸片是白纸，带柔和投影，倾斜 ±0.5°–1.4°（角度按位置算，逐帧不变）；格子、编辑器用精确细线 |
| **笔迹层** | 老师的批注：`ink` 手写字加弯箭头、`circle` 红圈、手写 ✓✗、荧光笔、标题下划线 | 手写体（漫黑 + Excalifont），笔画用 `scripts/lib/pen.ts`（和白板版同一个生成器） |
| **实物** | `sticky` 便利贴、`stamp` 图章、胶带 | 便利贴只放关键提醒；图章只盖结论；问题卡用胶带贴在右上角 |

**判断标准**：书上本来就有的内容放纸片层；老师讲课时加上去的放笔迹层。比如格子上的"字符""前驱"、`(c, a, t)` 是标签，留在纸片上；"挤不进来""该显示哪一行？"是讲解，写成批注。

## 规则

- 每帧最多 2 处批注，写在右半屏的空白处，用箭头指向目标。箭头终点必须落在目标元素上（分镜墙生成后用脚本检查）。

- **暗场**（`dark: true`，或者用 `lead` 做前半拍）：深墨绿底，浅色手写大字。只用在点名时刻：2.1 用在拍 12"线性表"、拍 13"编辑器 1.0"、拍 21 前半拍"什么是线性表"、拍 87 前半拍的小结。

# 备份风格：贴纸版（2026-10-13 定为落地方向）

参考原片"一部手机里藏着多少种元素"（贴纸风科普）。生成命令 `npm run storyboard -- 2-1 --sticker [--palette p0]`，帧文件 `docs/course/storyboard/2-1.sticker.frames.ts`（帧位和纸面版逐拍对应），主题 `scripts/lib/sticker.ts`，色系 `scripts/lib/palettes.ts`。分镜墙右上角可以切色系，也可以用 `?palette=n1` 直接打开。

## 画面元素

| 元素 | kit 函数 | 用法 |
|---|---|---|
| 贴纸 | `stk`、`sed`（编辑器）、`key`（按键） | 白边、圆角 12、柔和投影，可以倾斜（角度写在帧里，逐帧不变） |

| 大数字 | `bignum` | 长度、要点数、问题编号这种"一个数说明一切"的时刻 |
| 结论 | `chip`、`chk` | 胶囊标签、圆底勾叉 |
| 进度 | 帧文件里的 `steps`、kit 的 `qmini` | 标题下的五个要点胶囊代替手风琴；右上角三问小卡代替问题卡 |

## 规则

- **强调色只给"正在讲的那个 / 对的那个"**，每帧最多 2 处。
- **错误不用颜色**：`wrong()` 把内容去色、压暗到 50%、划一道灰线；✗ 是灰色圆底（`chk('no')`）。这条和色系无关，所以每套色系都成立。
- 标题不超过约 15 个汉字，不能压到右上角三问卡。
- 帧文件、kit 的贴纸元素、sticker.ts 里不写色值，只用 `var(--xxx)`；分镜墙生成后 grep 检查。
- 字号下限仍是 12px（画布），格子边长不小于 27px（字 = 边长 × 0.46）。
- 暗场只用在节尾小结（拍 87）：整课缩进编辑器贴纸，打出大数字。
- 分镜墙上新出现的元素用紫色虚线框标出（审帧标记，不属于画面）。

## 色系令牌

每套色系是一组语义令牌，输出成 `[data-palette="id"]{--bg:…}`，默认那套同时挂在 `:root` 上：

`--bg --dot --ink --mute --paper --tile --tile-ink --off --off-ink --acc --acc-soft --acc-ink --acc-line --ok --wrong --dark --dark-dot --dark-ink --dark-mute --big --big-stroke --big-stroke-w --field --field-line --ptr`

- `--acc-line` 是强调色的线和小字。强调色太浅时（N1 浅黄、M2 芥末）退回深色，否则细线和小字看不清。
- `--ptr` 指针紫，所有色系一样。

播放器页面：`player/<id>/sticker.html`，外壳跟着色系走，页面上可以切色系，选择记在 localStorage。

现有色系：**p0（默认，原片冷灰·炭·朱橙）**、p1 暖纸·墨·番茄红、p3 雾白·深青·珊瑚、n1 Nord 极光、z1 中国色宣纸·黛蓝·赭石、m2 莫兰迪灰蓝·芥末。P4 电光蓝不收，因为它离指针紫太近。

**新增色系必须先过 `npx tsx scripts/palette-check.ts`**：
- 对比度：正文、次要文字 ≥ 4.5；格子里的大字 ≥ 3；
- 色差：强调色和指针紫 ΔE2000 ≥ 20；强调格子和普通格子、熄灭格子之间 ≥ 20。

播放器已经能切换色系（2026-10-14）。视频导出时用 `--style sticker`；导出时用哪套色系，暂时固定为默认的 p0。

## 版面和图

- **同一屏版面不变，变化在原位发生**。Gauth 开场约 55 秒只用了 2 种版面，元素在原位一个个加上去。只有讲到新场景时才换版面。第0屏 16 帧只用两种：封面屏（拍1–12）和问题屏（拍13–20）。
- **标题的位置全课只有两种**（照 Gauth 开头逐秒对照，2026-10-14 定）：
  - **封面屏**：课程标题居中，从第一帧就和场景图一起出现，作用是告诉观众"这一课讲什么、学完能做什么"，只在封面出现。核心思想用"一个想法：……"副标题，讲到时才出现。
  - **其他所有屏**：左上 (40,16) 小标签 + (40,44) 宋体屏标题，给这一屏命名。
  - 反例（已改掉）：开场图缩成没有字的缩略图放在左上角，章号和标题挤到它右边、靠近中间，既不在封面中线上，也不在内容屏的左上角，看着突兀、杂乱。

## 线性表的三层画法（整章固定）

| 层 | 用在 | 画法 |
|---|---|---|
| 逻辑 | 2.1–2.2 线性表 | 分开的圆角方块，中间留 8px 空隙（`cells()` 默认）；**位置标在方块上方**（a₀ a₁ a₂，作者定），不在下方标 0 1 2（下方留给 2.3 的地址）；旁边写 `(c, a, t)` |

## 分镜检查清单（2026-10-14 第0屏重做的经验）

做完一屏、改完一屏，都过一遍这张清单。

1. **先量，再判断**。运行 `npm run storyboard:audit -- 2-1 --clean`（加 `--shots <目录>` 会出逐帧截图和每屏联系表）。看三个数：
   - 每屏几种版面；
   - 每帧多长时间；
   - 相邻帧的**稳定率**：两帧都有的元素里，有多少没挪位置。
   
   "开场太长"这类感觉，先用数字核对。第0屏实测 51 秒、Gauth 约 55 秒，时长差不多；真正的差别在版面数：我们 16 种，Gauth 2 种。
2. **一屏一到两种版面**。稳定率低于 60%（东西挪了）或保留率低于 30%（几乎整屏换掉），算换版面，只允许出现在新场景开始的地方。
   - 指标里，高亮移动（on/hl/dim/off 这几个状态类）和元素消失都不算挪位置。
   - 起初只用保留率衡量，把手风琴说得比实际更糟（15%）；改用稳定率后实测是 64%–93%。所以两个数都要看。
3. **固定槽位**：主角元素（编辑器、键帽位、说明行、演示卡）的位置整屏不动。同一元素的几个状态叠在原位，用 `reveal: 'spread'` 依次出现。
   - 文字要"由淡变亮"（先淡着、讲到时亮起，比如 2.1 拍13–14 的目标小字），只放一份字，写 `class="new" data-from=".4"`：播放器从 0.4 原地亮到 1，不上移。不要淡、亮两份叠在一起：对不齐就是重影（行内文字开头的空格进了绝对定位会被折叠）。
4. **要点、步骤用左右两栏，不用手风琴**：左栏行高固定、当前行高亮，右栏演示卡位置固定，内容在原位换或追加；能拆阶段的就螺旋递进。写法见 `docs/teaching-patterns.md` 第 13 条"左右对照，螺旋递进"，代码节（2.12 起）默认用它。
5. **问题线索用同一个元件贯穿**：开场的问题胶囊（`cqpill`）→ 第1屏标题上方的"问题 1"小标签 → 小结里给这枚胶囊打 ✓ → 节尾三枚胶囊再出现，1 打勾、2 高亮。
6. **标题位置和整屏平衡**：封面居中、其他屏左上，位置全课统一；数据卡跨屏保持同一个样子；删掉或合并一个元素后重排整屏，不能留大块空白（看联系表时专门检查右半边和下半边）。
7. **改完结构，顺手查旁白重叠**。画面一合并，重复的句子就暴露出来了，比如原拍15和拍9。删旁白时拍号不重排，所有帧文件只改受影响的那一帧。
8. **先少量、后全量**：先挑几帧做三栏对比（原版 | 只换样式 | 样式 + 重排），作者定了再改全部。
9. **自检**：元素不出画布、字号不小于 12px（audit 会报）；出联系表，人眼逐帧看一遍；核对没改的旧版本有没有被误改（重新生成，比 md5）。
