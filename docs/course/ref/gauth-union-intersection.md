**这一节的知识类型**：交集、并集都是**过程型知识**，回答的是"给两个集合，怎么得出新集合"。所以和列举法一样，放在例题里讲。

## 二、知识单元

| 单元 | 知识类型 | 讲法 |
|---|---|---|
| 交集、并集（一个单元，两个运算） | 过程型 | 预告符号 → 每个运算：一句规则 → 用场景数据详做 → 回答挂起的问题 → 两个运算一起换数字略做 → 验算 → 练习 |

两个运算放在同一个单元里：先各自详做，再在同一屏里一起略做，最后用一道题同时检验两个。

## 三、写作手法

**预告**
1. **先给符号，并提醒两者容易混**。在定义之前，让学生先预览每个符号的意思。

**每个运算的详做（场景数据）**
2. **一句规则**就开始做，不展开解释。规则里带上"只有这些"这类限定。
3. **容易错的规则在做之前点名**："每个元素只写一次"。
4. **一拍判断一个元素，句型固定**：只在 A，跳过；两边都有，放进去；已经有了，跳过。
5. **并集的做法写成两步**：先把 A 全部抄进去，再逐个加 B 的元素。
6. **老师故意犯一次错**，再纠正：写进重复的 honey，然后划掉，把容易错的地方演出来。
7. **结果回答开场挂起的问题**：例题用的是场景里的数据，算完正好回答店主的问题，问题胶囊打勾。

**换数字略做**
8. **"同样的动作，换成数字"**：两个运算一起再做一遍，提示减少。
9. **在略做里给一个技巧**：按从小到大写。
10. **验算**：数个数，并检查共有的元素只出现一次。

**练习**
11. **一题两空，两个运算一起考**，共用一个选项池。
12. **干扰项按错误类型出**：
    - {3,4,6,6,8,9,12,12}：重复，违反"只写一次"；
    - {12}：交集漏了一个；
    - {3,9}：只在 M 的，做成了另一种运算；
    - {3,4,8,9}：只在一边的，也是做成了别的运算。

    另一个空的正确答案本身也是干扰项，比如把交集的答案填进并集。
13. **练习前一句提醒**：守住"不重复"这条规则。

## 四、画面层的观察（只供动画参考，不进写作方法）

- 翻牌卡是交互，课程停下来等学生点。
- 两个集合固定在屏幕上方，结果框在下方；判断时只改元素状态：变灰、加小字"只在 A"、上下连线。
- 重复元素先画红圈，再划掉，旁边写一行红色小字"每个元素只写一次"。
- 问题胶囊在结果出来时打勾，换成"共有：banana、honey""一共 7 种"。
- 换数字时版面不变，只换数据。

## 五、借用时要注意的前提

2.2 做课程时已经定过借哪些（见 `docs/course/2-2.md` 开头的取舍表）：
- 借：开头直接讲工具；场景只当演示；一拍判断一个元素；例题和练习同型；一题两空、共用选项池；练习前一句话提醒规则。
- 不借：翻牌卡、"双胞胎"钩子、老师故意犯错。Insert 和 Delete 并不容易混。
- 不借："不重复"的规则和"有重复"的干扰项。线性表允许重复。

这些"不借"的判断都是针对线性表的，不是说这些手法不好。别的内容如果真有容易混的一对、真有常犯的错，照样可以用。

## 六、和列举法的对比

作者的判断：列举法和交集、并集都是**过程型知识**，所以都放在例题里讲，是同一种写法。

| | 列举法（Roster Notation） | 交集、并集 |
|---|---|---|
| 知识类型 | 过程型：描述 → 列举的转换 | 过程型：两个集合 → 新集合的运算 |
| 开头 | 说出要转成什么，名字先说，不解释 | 说出名字（和符号）加一句规则，不展开 |
| 详做 | D：逐个检验候选，一个边界上的反例（9） | 用场景数据逐个判断元素；并集里老师故意犯一次错 |
| 略做 | E：一句带过 | 换成数字，两个运算一起再做一遍 |
| 验算 | 数个数，一个不漏、一个不重 | 数个数，共有的元素只出现一次 |
| 练习 | 口诀；同型；干扰项各违反描述里的一个条件 | 一句提醒；同型；一题两空；干扰项按错误类型出 |

**结论：骨架相同，是同一种写法。** 两者都是：

> 开头一句（名字加规则，或者目标形式）→ 详做一例 → 略做一例 → 验算 → 同型练习

交集、并集多出来的都是**变体**，在骨架上加一步或换一种做法：
1. **运算有规则时，开头给一句规则**，规则里带上限定词。
2. **有容易错的规则时，做之前先点名，详做时故意犯一次错再纠正。**
3. **成对的运算放在同一个单元**：先各自详做，再一起略做，用一道一题两空的练习同时检验。
4. **详做用场景数据，结果回答挂起的问题；略做换成更干净的数据**（数字）。这和描述型概念"场景贯穿主线、对照换干净材料"是同一条原则。
5. **略做时可以给一个技巧**，比如按从小到大写。
6. **干扰项的原则可以统一成"每个干扰项对应一种具体的错误"**：违反一个条件、漏掉、重复、做成另一种运算。

另外更正一点：之前我以为两者的命名顺序不同。实际上**都是先说名字**（列举形式、交集），只是交集多了一句规则。所以过程型知识的命名顺序统一为：先给名字和一句规则或目标，再用例题让它变具体。
