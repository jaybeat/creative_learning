# 书稿写作要求：能直接切节拍、念成旁白

**适用范围**：所有书稿，不分概念类型。修改旧书稿、新写书稿都按这份要求。

**目标**：书稿写好之后，**旁白只需轻微调整，节拍骨架可以直接从书稿切出来**。

**证据**：2.1 实测，旁白里原样 63%、小改 33%、新写 3%（`docs/course/ref/2-1-retro.md`）。

书稿决定在哪里切、每拍出现什么对象。对象画成什么样、放在哪里，是画面设计的事，见 `docs/course/visual-spec.md`。

---

## 要求

1. **一段只讲一件事**，以后一段就是一个拍组。
2. **一句话对应一个能出现在画面上的对象**。句子短，大约 18 个字以内；长句在标点处能拆开。
3. **讲到的要点、步骤，都有一个能画出来的对象**，比如一个最小对照、一步做完后的样子。
4. **符号第一次出现时先用文字说**："第0个元素记作 a₀"。
5. **论证写在段落里**，表格只做汇总。
6. **少用括号和嵌套**，补充说明单独成句。
7. **交叉引用单独成句**，做旁白时整句删掉不影响意思。
8. **不写指代版面的话**，比如"下面是""如图"。
9. **一页书对应一个版面**。一页念出来超过约 90 秒，说明讲了不止一件事。
10. **不写不值得念的话**：做动画时被删掉的句子，书稿里多半也不需要。

## 不算书稿问题的改动

做旁白时还要做一些机械改动，这些在双栏稿里改：
- 删指代词；
- 写清符号念法：a₀ 念"a 零"，(c, a, t) 念"c、a、t 组成的表"；
- 给加粗的要点名加序数："第一，同类型"；
- 练习的题干和选项不念，只念"轮到你了"加一句方法口诀。

## 自检

随便挑一段念出来，不看图也能听懂。
