# 引导模块：念到哪，看到哪

配音讲解时，旁白点名画面上的某个东西，那一刻画面要把眼睛带过去。本模块做三件事：

- **移动**：拍内换状态时，同一个元素从旧位置滑到新位置（读头往右走、入栈、出栈、写到输出带）；
- **指示框**：一个深蓝细框指向正在说的东西，在目标之间滑动，像老师的手指；
- **批注**：对框住的东西下判断时，框旁画一根红色短箭头，写出四五个字的"为什么"。

它和讲的是什么内容无关：画面元素起好名字，帧上写好"念到哪个短语、做什么"，就能用。2026-10-28 在 3.6 上定稿，取舍的理由见文末。

## 文件

| 文件 | 内容 |
|---|---|
| `cues.ts` | `Cue` 类型、`normSpeech`、`locateCues`（在旁白里找短语）、`phraseTime`（短语的起止秒数）、`cueTimeline`（一帧的 cue 换成绝对时间的状态和聚焦区间） |
| `timing.ts` | `charTimes`：调用 `scripts/course_tts.py --times` 用 faster-whisper 转写每拍配音，记下每个字的时间，存在 `audio/bNNN.t.json`；没有转写时按字数比例估 |
| `runtime.js` | 浏览器端。上半部分是纯计算（`groupRects`、`focusState`、`glideRect`、`notePlace`、`noteState`，测试见 `tests/unit/guide-runtime.test.ts`），下半部分 `createGuide(env)` 负责画面层、拍内状态、滑动、指示框、批注 |
| `guide.css` | `.fx-ring`（指示框）、`.fx-note`、`.fx-arrow`（批注）。颜色取主题变量 `--c1`、`--note` |

课程播放器（`scripts/course-player.ts`）生成页面时把 `runtime.js`（去掉 `export`）和 `guide.css` 内联进去，播放器的 `render(t)` 只管选帧、音频、字幕、练习，画面交给 `guide.frame(time, ci, step)`。画面只由时间 t 决定，导出视频时逐帧调用也一样。

## 怎么用

### 1. 给元素起名

指示框、批注、滑动都按名字找元素：

- `data-k="名字"`：同一个名字在前后两个画面里就是同一个东西，会滑过去；聚焦也按它找。
- `data-src="另一个名字"`：新出现的元素从那个元素的位置滑过来，比如写到输出带的数字从读头下那一格滑过来。

`docs/course/storyboard/kit.ts` 的元件已经支持：

- `ctape(chars, { k, names, src })`：第 i 格叫 `k-i`，读头 `k-head`，下划线 `k-u`，虚线框 `k-box`；`names` 单独给某格起名（比如运算符按字叫 `op+`，出栈时能从栈里滑到输出带）。
- `cstack(items, { k, names, src })`：第 i 个元素 `k-i`。

自己写的卡片，在要指的元素上加 `data-k`。

### 2. 在帧上写 cue

```ts
{ beat: 74, html: 动作前的画面, cues: [
  { at: '4和2都齐了', focus: 'out-1,out-2' },                // 指示框
  { at: '弹出', steps: [动作后的画面] },                       // 念到"弹出"才动
  { at: '`*`在等它的右边', focus: 'op*', note: '等右边' },     // 框 + 批注
] }
```

- `at`：这一帧旁白里的一个短语（去掉反引号、标点后匹配）；几个 cue 按顺序往后找，找不到会报错。
- `steps`：拍内的画面状态，均匀摊在这个短语的时长里。
- `focus`：目标的名字，逗号分开可以几个；挨着的格子合成一个框，分开的各一个框。到下一个 `focus` 或这一帧结束为止。
- `note` / `side`：框旁批注和写在哪边（默认右边，放不下自动换左边、下面；`'b'`、`'l'` 可以指定）。
- 帧上 `cut: true`：换到这一帧时照旧交叉淡入、不滑动，用在闪回、换例子（滑过去会像倒放）。

### 3. 生成和检查

- `npm run storyboard -- <id>`：分镜墙每帧下面列出 cue（短语 → 状态小图、聚焦、批注）。
- `npm run storyboard:audit -- <id>`：核对聚焦的目标存在、拍内状态不出画布，并列出"静止拍"（念 4 秒以上，画面上既没有新元素也没有 cue）。
- `npm run course:player -- <id>`：只给写了 cue 的拍转写每字时间（本地计算，不花合成的钱）；`COURSE_TIMES=0` 跳过。

## 规则（作者 2026-10-28 定）

- **只用局部变化**：不压暗别的东西，不放大（`zoom` 不再用）。整屏一暗一亮、整屏缩放，比目标本身更抢眼。
- **框不熄灭**：一串聚焦只在开头淡入、结尾淡出，中间从一个目标滑到下一个；同一屏换帧也接着滑。
- **动作在动词那一刻**："弹出""入栈"这类动作，帧里先画动作前，念到动词时用 `steps` 换成动作后。
- **静态小字还是批注**：看这句话是"图的一部分"还是"老师当下说的一句话"。
  - 名字和标签、会更新的记录、约定、定义、结论、结果、对照表，留在画面上；
  - 念到这一刻才说的提问、判断、理由，改成批注。
  - 批注同时最多一条，框滑走前淡出。
- **不和静态描边叠**：被聚焦的元素去掉原来的"正在比"描边。
- 位置按屏幕上的实际位置量（`getBoundingClientRect`）。用 `offsetLeft` 一路加会漏算外层边框，框会偏几像素。
